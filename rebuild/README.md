# בניית המעבדה מאפס — 27.9.2026

החבילה הזו בונה מחדש את כל מעבדת ה-SCOM מאפס, בלחיצה אחת, מהסקריפטים המוכחים שכבר בנו אותה בפעם הראשונה.

## מה קורה הלילה (הכנה בלבד, $0)
1. `scripts-backup-mega` — גיבוי git מלא טרי ל-MEGA (רץ).
2. `rebuild-00-inventory` — צילום מצב חי: משאבים, מצב כוח, דיסקים, עלות 30 יום. קריאה בלבד.
3. הקוד כאן מוכן: תרזה, מחקה, בנייה.

## מה קורה מחר (רק אחרי אישור שלך בוואטסאפ)
1. **גיבוי אומת** ב-MEGA (git bundle + יצואי MP כבר בריפו).
2. **תרזה יבש**: `rebuild-teardown` עם `DRYRUN` — מדפיס בדיוק מה יימחק. אתה מאשר את הרשימה.
3. **מחיקה**: אותו וורקפלואו עם `DELETE`. מוחק רק את *תוכן* `rg-learning-monitoring`.
   נשאר: ה-RG עצמו + 5 מדיניות השמירה, `rg-esther-portal` (אסתרדקסס), כל ה-Entra, מדיניות המנוי, הכספת.
4. **בנייה**: `rebuild-master` עם `until=all`. סדר: מדיה (מורידה SQL+SSRS+SCOM במקביל לכל השאר) → רשת+VM → DC+AD → join → SQL → דרישות → SCOM+MPs+סוכן DC → לינוקס שוודיה → סוכן לינוקס → אימות.
   אפשר לעצור בכל תחנה (`until=sql` וכו׳) ולהמשיך אחר כך — כל שלב אידמפוטנטי.

## עלות (מהמדידות שלנו, יאומת שוב ב-inventory)
- מעבדה דולקת: ~$0.095 לשעה. כבויה (דיסקים HDD): ~$7.2 לחודש.
- DC על 750 השעות החינמיות של B2ats_v2. SQL Developer + SCOM הערכה = $0 רישיון.
- הכול מהקרדיט של $200 (נגמר ~20.10). מגבלת ההוצאה דולקת. הכרטיס לא נגוע.
